# 🛒 E-Commerce Web Application

A full-stack **E-Commerce Web Application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

The project provides a complete online shopping experience with user authentication, product browsing, cart management, checkout, order booking, payment integration, and an admin dashboard for managing products and orders.

## 🚀 Features

### 👤 User Features
- User Registration and Login
- Google Authentication
- Browse Products
- Product Details
- Product Search
- Product Categories
- Size Selection
- Add to Cart
- Cart Management
- Checkout
- Order Booking
- Online Payment Integration
- Responsive Design

### 🛠️ Admin Features
- Admin Dashboard
- Add Products
- Update Products
- Delete Products
- Product Management
- Order Management
- View User Orders
- Manage Store Data

### 🔐 Security
- Authentication and Authorization
- JWT-based authentication
- Protected API routes
- Secure user sessions
- CORS configuration

## 🧑‍💻 Tech Stack

### Frontend
- React.js
- JavaScript
- Tailwind CSS
- Axios
- React Router
- React Icons

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Authentication & Payment
- Google Authentication
- Firebase / Google API
